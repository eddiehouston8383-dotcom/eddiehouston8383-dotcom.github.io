How the sheets teach

A plain cheat sheet does not teach. Reading the same page twice helps a little. Testing yourself helps a lot — people remember 56% a week later when they test themselves, against 42% when they only re-read. So every SOL Studio sheet is built around doing.

Every lesson follows the same loop

  1. Goal — one clear thing you will be able to do.
  2. Worked example — a real example with real output, explained in plain words.
  3. Try it — change one thing, guess what happens, then run it.
  4. Watch out — the classic mistake for this topic, and how to fix it.
  5. Practice check — two quick questions to test yourself.
  6. Project — a small, real thing you build at the end of the sheet.

Built for total beginners

  • Plain 9th-grade words — every new word is defined the first time you meet it.
  • One idea per page, so nothing feels crowded.
  • Phone-friendly — big type, short lines, and code you can read on a small screen.
  • Safe by design — practice folders only, and the dangerous commands are clearly marked.
  • Rewind and self-check at the end of every sheet, so you can see what you know.

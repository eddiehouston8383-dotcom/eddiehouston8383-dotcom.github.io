# SOL Studio — GitHub Pages site

This is the **public** website for SOL Studio Education:
**https://eddiehouston8383-dotcom.github.io/**

It is a shop window, not the product. It lists the 10 lesson-style cheat
sheets, explains how they teach, and points buyers to Etsy. It does **not**
contain the paid PDFs.

## What lives here

- `index.html` — the whole site, one self-contained page (no external
  JavaScript, no CDN, system fonts only). Deep-space navy + sun-gold theme,
  plain 9th-grade words.
- The Etsy "Buy" buttons link to `#` for now — the listings are not published
  yet. They are clearly marked "coming soon". Do not invent a shop URL.

## What does NOT live here

The paid PDFs live in the **private** repo
`eddiehouston8383-dotcom/sol-studio-education` and must never be committed
to this public repo:

- Prompt Engineering Guide (22pp), Python Basics (12pp),
  Python Functions &amp; OOP (16pp), Linux (16pp), Shell Scripting (10pp),
  SQL (18pp), Git (12pp), Cybersecurity (9pp), Nmap Pro (14pp),
  DevOps Basics (16pp) — 145 pages total.

## Publishing

GitHub Pages serves this repo automatically. Push a change to `main` and the
live site updates. Keep the footer support email
(eddiehouston8383@gmail.com) on the page, and do not add any store link.
